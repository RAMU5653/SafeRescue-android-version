# SafeRescue Design System — Phase 1

## Reference material

The supplied SafeRescue brand artwork is the visual anchor. The supplied system infographic is retained as an architecture/reference board.

## Visual language

- Primary: deep indigo / violet
- Accent: magenta-pink
- Surface: soft near-white
- Safety state: high contrast, text-first, not color-only
- Shapes: generous but controlled rounded corners
- Typography: strong display title + readable supporting text

## UX rules

1. Emergency state must always have higher visual priority than decorative content.
2. Never communicate emergency state by color alone.
3. Touch targets should be comfortably large.
4. Motion must communicate state change, progress, or confirmation — not decoration.
5. Loading and failure states must be explicit.
6. AI indicators must be described as indicators, never as proof of a crime.
