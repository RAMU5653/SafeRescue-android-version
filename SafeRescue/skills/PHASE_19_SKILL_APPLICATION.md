# Phase 19 Skill Application

## Impeccable / Taste / Motion
- Keep hardware status explicit and non-blocking.
- Avoid decorative BLE animations that imply emergency delivery.
- Use controlled state feedback only when a real GATT state exists.

## Cybersecurity skill application
- Threat model BLE spoofing, replay, unauthorized writes and permission abuse.
- Use authenticated bounded packets and runtime key provisioning.
- Never send raw victim evidence over BLE.
- Treat hardware failure as recoverable and never as emergency failure.
